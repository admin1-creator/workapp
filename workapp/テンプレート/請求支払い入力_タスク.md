# 請求支払い入力 — タスク一覧

仕様書を実装できる単位に分解したものです。チェックは「そのタスクがコード上できたか」です。

- [x] 完了（現状のアプリで動いている）
- [ ] 未着手（企画で今期に入れるもの）
- [ ] ~~対象外~~ は「やらないこと」

---

## いま動いている（保守・仕様どおり残す）

- [x] 1画面入力（伝票番号・日付・現場・元請・職人・手元最大3・応援・作業最大15行）
- [x] 作業内容0行は保存しない
- [x] 手元の重複選択を防ぐ
- [x] 手元人数で職人控除（0人0% / 1人35% / 2人以上40%）
- [x] 手元の個人％は手元の支払だけに使い、職人控除には使わない
- [x] 元請・職人（個別→共通）・応援の単価マスタと自動取得
- [x] 保存前の確認画面
- [x] 一覧（相手を選んで保存済みを表示）
- [x] 編集・更新確認・削除
- [x] 単票印刷
- [x] 期間指定印刷（開始日・終了日・相手）
- [x] 月次集計（当月）
- [x] 手元設定画面（個人％）

## 今期の追加（希望機能）

### 相手別の保存画面を4つに揃える

- [x] 一覧の選択を「元請 / 職人 / 手元 / 応援」の4択にする（職人と手元を分ける）
- [x] 期間印刷の相手選択も同じ4択にする
- [x] 帳票タイトルを元請=請求書、職人・手元・応援=支払書にする

### 印刷済みが分かる

- [x] 印刷書類テーブル（相手・期間・種別・合計・状態・印刷日時）
- [x] 書類と作業記録の紐づけ（行金額のスナップショット）
- [x] 期間印刷の「印刷済みにする」
- [x] 一覧に印刷済み / 未請求の表示
- [x] 同じ内容の再印刷（固定金額のまま）
- [x] 印刷取消（伝票を未請求に戻す）
- [x] 印刷済みは直接編集・削除しない（取消後のみ）

### 元請の締め日

- [x] 元請マスタに締め日（1〜31）
- [x] 元請一覧で「今の締め対象期間」を表示する
- [x] 未請求件数を表示する
- [x] 締め日なしでも手入力の期間印刷はできる

### 印刷後の金額固定

- [x] 印刷後に単価マスタを変えても、印刷済み書類の金額は変えない
